# Sport Team Manager API

NestJS REST API bootstrap for the Sport Team Manager modular monolith.

## Commands

```bash
npm ci
npm run prisma:generate
npm run start:dev
```

Quality checks:

```bash
npm run prisma:validate
npm run lint
npm test
npm run test:e2e
npm run build
```

Copy the repository `.env.example` to this directory as `.env` before local development. Business modules are introduced only with a validated vertical slice.
